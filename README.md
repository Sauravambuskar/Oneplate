# PlateHope Foundation website

A responsive five-page website built with Next.js, Express and GSAP.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

## Pages

- Home
- About
- Our Work
- Get Involved
- Contact

The Express server provides `/api/health`. Contact form submissions and the floating contact button open WhatsApp for `+91 97738 85463` with a prefilled message.
